# 커뮤니티 목록

지식 그래프의 22개 커뮤니티(기능 군집)를 응집도와 함께 정리합니다.

## 대형 커뮤니티 (10+ 노드)

### 0. Main App UI Logic (44노드, 응집도 0.09)
앱의 핵심 UI 흐름을 담당하는 가장 큰 커뮤니티입니다.
- `init()` — 앱 초기화
- `activateMissionRegion()` — 지역 미션 활성화
- `renderMissionPanel()` — 미션 패널 렌더링
- `updateProgress()` — 진행 상황 업데이트
- `renderFilters()` — 필터 UI 렌더링
- `showReward()` — 보상 표시
- `bindViewTabs()` — 뷰 탭 바인딩
- `debounce()` — 디바운스 유틸리티

> 응집도가 0.09로 매우 낮습니다. 이 커뮤니티는 UI 렌더링, 상태 관리, 이벤트 핸들링이 뒤섞여 있어 리팩토링 여지가 큽니다.

- `createInitialBoards()` — 초기 보드 생성
- `handleQuizAnswer()` — 퀴즈 답변 처리
