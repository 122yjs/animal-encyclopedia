# 동물도감54 프로젝트 개요

## 프로젝트 소개

**동물도감54**는 초등학교 3학년 과학 「동물의 생활」 수업용 게임형 동물도감 웹 애플리케이션입니다. 학생들이 동물을 수집하고 퀴즈를 풀며 학습하는 게임화된 경험을 제공합니다.

## 기술 스택

- **Frontend:** 순수 Vanilla HTML/CSS/JS (zero-dependency)
- **Build:** Node.js 기반 커스텀 빌드 스크립트 (`scripts/build.js`)
- **Framework 버전:** React + Vite 기반의 게임화 웹앱 (`gamified-animal-encyclopedia-webapp/`)
- **이미지:** Wikimedia Commons에서 런타임 로드 (로컬 이미지 에셋 없음)
- **배포:** GitHub Pages (GitHub Actions 자동 배포)
- **저장소:** `localStorage` (`animal-encyclopedia-collected-v1`)

## 주요 기능

### 1. 동물 도감 (Encyclopedia)
- 54마리 동물의 특징, 서식지, 생활 습관 정보 제공
- 지역별 필터링 (숲, 바다, 사막, 북극, 우리 동네, 특별)
- 동물 상세 정보 모달 (관찰 체크리스트, 퀴즈)

### 2. 게임화 요소 (Gamification)
- **수집 시스템:** 동물 카드를 수집하여 도감 완성
- **지역 보상:** 각 지역 완성 시 별 보상
- **최종 미션:** 모든 동물 수집 시 마스터 보상
- **온볼딩:** 첫 실행 시 튜토리얼 가이드

### 3. 퀴즈 시스템 (Quiz)
- 동물 특징, 서식지, 행동 관련 문제 생성
- 4지선다형 퀴즈
- 힌트 시스템과 피드백
- 관찰 체크리스트 연동

### 4. 교사용 질문방 (Question Tool)
- MagicSchool 학생용 참여 링크 연동
- QR 코드 생성 및 공유
- 설정한 질문방 링크가 포함된 수업용 URL 생성

### 5. 미션 시스템 (Mission)
- 교사가 특정 동물들로 미션 구성
- URL 파라미터로 미션 공유
- 미션 진행 상황 시각화

```
├── index.html              # 메인 진입점 (질문방 설정 포함)
├── no-question.html        # 질문방 없는 버전 (자동 생성)
├── app.js                  # 핵심 애플리케이션 로직
├── app-config.js           # 런타임 설정
├── styles.css              # 스타일시트
├── vendor/qrcode.js        # QR 코드 생성 라이브러리
├── scripts/
│   ├── build.js            # 배포 빌드 스크립트
│   ├── generate-no-question.js  # no-question.html 생성
│   ├── download-local-images.js # 위키미디어 이미지 다운로드
│   ├── generate-credits.js # 이미지 출처 생성
│   └── *-contract.test.mjs # 계약 테스트
├── docs/                   # 개발 문서
│   ├── ROADMAP.md
│   ├── QA_CHECKLIST.md
│   └── archive/            # 과거 개발 기록
├── assets/sprites/         # 게임 스프라이트 (부엉이, 지역 뱃지, 아이콘)

```

## 핵심 인사이트

### 가장 연결된 함수: `init()`
- 21개의 연결을 가진 그래프의 중심 노드
- 앱 초기화, 미션 설정, 질문방 구성, UI 바인딩 등 모든 시작점

### 크로스 커뮤니티 브리지: `playSound()`
- 게임화 웹앱 ↔ 메인 앱 ↔ 퀴즈 흐름을 연결
- 4개의 INFERRED 엣지로 인해 예상치 못한 연결 다수
- 사운드 시스템이 실제로는 전체 앱의 공통 유틸리티로 작동

### 약한 응집도 커뮤니티
- Main App UI Logic (0.09), Gamified Webapp & Game (0.09), Core App Functions (0.12)
- 이들은 하나의 거대한 모듈로 병합하거나, 더 세분화된 모듈로 리팩토링할 여지가 있음
